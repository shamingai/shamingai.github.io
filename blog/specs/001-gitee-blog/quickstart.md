# Quickstart: Gitee 博客

本指南验证已发布的静态站点。它不启动内容管理服务，也不提供在线编辑。

## 准备

1. 准备一组本地文章、一份关于介绍和一条历史事件。
2. 其中包含：
   - 45 篇可发布文章，覆盖至少两个年份。
   - 同一天的两篇文章，标题顺序可区分。
   - 父分类「人工智能」和子分类「深度学习」。
   - 一篇直接归入父分类，一篇直接归入子分类。
   - 一篇文章带两个标签。
   - 一篇正文为空的文章、一篇填写两个分类的文章。
   - 一条指向未发布文章的历史事件。
3. 运行项目的站点生成命令，输出到一个本地目录。
4. 用静态文件服务打开该目录。不要启动 `backend/` 作为阅读站点。

## 验收

| 场景 | 操作 | 预期 |
|---|---|---|
| 首页 | 打开 `/` | 只见已发布文章；最新在前，同一天按标题；每篇有标题、摘要、一个分类和全部标签 |
| 正文 | 从首页进入一篇文章 | 可见发布日期、字数、阅读时间、正文和有效目录；上一篇、下一篇符合首页顺序 |
| 归档 | 打开 `/archive` | 显示「共有 45 篇」；年份内从旧到新；分页覆盖 45 篇且不重复 |
| 分类 | 打开父分类和子分类 | 父分类看不到子分类文章；两边数量只等于各自直接文章数 |
| 标签 | 打开文章的两个标签 | 两个标签页都能找到该文章；文章仍只有一个分类 |
| 搜索 | 搜索标题、摘要、正文和一个未发布词 | 前三项能找到已发布文章；未发布词没有结果 |
| 关于与历史 | 分别打开两个页面和归档 | 关于是介绍，历史是事件，归档是文章；失效文章没有历史入口 |
| 发布边界 | 检查生成目录和页面入口 | 没有在线编辑、后台、绑定或上传入口；被拒绝文章有作者可见的原因 |

详细页面规则见 [contracts/reader-pages.md](contracts/reader-pages.md)，字段规则见 [data-model.md](data-model.md)。
