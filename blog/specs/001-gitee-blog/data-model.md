# Data Model: Gitee 博客

## 文章 Article

已发布文章是读者可见内容的唯一文章实体。

| 字段 | 说明 | 规则 |
|---|---|---|
| id | 稳定身份 | 发布期间不变；文章不再发布后，旧地址表现为不存在 |
| title | 读者看到的标题 | 必填；用于同一天排序 |
| summary | 摘要 | 可空；为空时文章流显示「暂无摘要」，不截取正文 |
| body | 正文 | 必填；空正文不能发布 |
| category | 直接归属的分类 | 恰好一个；多个或缺失都不能发布 |
| tags | 标签 | 零个或多个；不改变分类 |
| publishedOn | 发布日期 | 必填；决定新旧和归档年份 |
| wordCount | 正文字数 | 按可阅读文字计算；0 不能发布 |
| readingMinutes | 预计阅读时间 | `max(1, ceil(wordCount / 400))` |
| headings | 正文目录 | 仅包含可定位标题；没有标题时不生成空目录 |

关系：一篇文章直接归入一个分类，可使用多个标签。

状态：输入内容要么成为已发布文章，要么被拒绝。被拒绝的内容不进入任何读者页面。

## 分类 Category

| 字段 | 说明 | 规则 |
|---|---|---|
| name | 分类名称 | 读者可见 |
| parent | 父分类 | 可空；用「父分类 / 子分类」表达层级 |
| articleCount | 直接归入的已发布文章数 | 不包含子分类文章 |

关系：分类可以有多个子分类。文章不从子分类继承到父分类。

## 标签 Tag

| 字段 | 说明 | 规则 |
|---|---|---|
| name | 关键词 | 与同名分类不合并 |
| articles | 使用该标签的已发布文章 | 至少一篇；否则不出现在可浏览入口 |

## 正文目录 Heading

| 字段 | 说明 | 规则 |
|---|---|---|
| text | 目录文字 | 来自正文标题 |
| anchor | 正文位置 | 选择后到达对应部分 |
| level | 层级 | 只用于展示层级，不参与文章排序 |

## 归档 Archive

| 字段 | 说明 | 规则 |
|---|---|---|
| total | 已发布文章总数 | 45 篇时显示「共有 45 篇」 |
| years | 年份分组 | 每组内按发布日期从旧到新，同一天按标题 |
| pageSize | 分页大小 | 默认 10；超过一页才提供分页 |

归档不包含历史事件。

## 搜索结果 Search Result

搜索数据只包含已发布文章的标题、摘要和正文。结果按发布日期从新到旧、同一天按标题排列。空关键词不产生结果请求。没有匹配时显示「没有找到相关文章」。

## 关于 About

作者介绍。它不是文章，没有分类、标签、归档年份或搜索索引。

## 历史事件 History Event

| 字段 | 说明 | 规则 |
|---|---|---|
| date | 事件日期 | 用于时间线排序 |
| text | 事件内容 | 不是文章正文 |
| articleId | 可选的相关文章 | 文章未发布时保留事件，移除入口 |

历史事件不计入归档总数，不出现在分类、标签或搜索中。

## 排序规则

- 首页顺序：`publishedOn` 降序，`title` 升序。
- 分类、标签、搜索使用首页顺序。
- 归档年份内：`publishedOn` 升序，`title` 升序。
- 上一篇是首页顺序中的前一项，下一篇是后一项。最新文章没有上一篇，最旧文章没有下一篇。

## 拒绝规则

以下输入不能发布，生成结果必须指出身份和原因：

- 正文为空或字数为 0。
- 分类缺失或多于一个。
- 发布日期缺失或无法识别。
- 标题缺失。
